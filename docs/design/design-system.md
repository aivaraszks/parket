# Parket design system

Tokens live in `src/styles.scss` as CSS custom properties on `:root`. Never hard-code values in components.

## Mood

Warm, classy: golden-oak herringbone parquet in sunlight, white heavy uppercase sans wordmark, retro film grain.

## Colour

| Token                    | Value                     | Use                                 |
| ------------------------ | ------------------------- | ----------------------------------- |
| `--color-floor-dark`     | `#2a190b`                 | page fallback, theme-color          |
| `--color-text-on-floor`  | `#ffffff`                 | text over the floor                 |
| `--veil-center`          | `rgb(40 20 8 / 0.08)`     | full-screen vignette, centre        |
| `--veil-edge`            | `rgb(24 11 4 / 0.55)`     | full-screen vignette, edges         |
| `--veil-warm`            | `rgb(255 170 80 / 0.04)`  | warm tint                           |
| `--veil-text`            | `rgb(28 14 5 / 0.62)`     | local dark pool behind the wordmark |
| `--sun-warm`             | `rgb(255 226 160 / 0.7)`  | sun glow (screen blend)             |
| `--sun-soft`             | `rgb(255 214 140 / 0.4)`  | window light shafts                 |
| `--sun-sheen`            | `rgb(255 240 200 / 0.28)` | broad glossy specular band          |
| `--sun-gleam`            | `rgb(255 244 214 / 0.55)` | one-time gleam sweeping the floor   |
| `--shine-color`          | `rgb(255 196 100 / 0.95)` | one-time golden shine across text   |

Contrast (white wordmark): the golden oak is mid-light (about `#c58a4a`, luminance about 0.32; sun-lit up to about 0.5). Under `--veil-text` (0.62) that blends to luminance about 0.10-0.17, so roughly 5.3-7:1 against white (AA needs 4.5:1; the text is large, so 3:1). Estimated, not measured: verify on a screenshot and raise `--veil-text` alpha if a sun shaft crosses the text. The film grain at 0.55 overlay is neutral on average and does not shift luminance noticeably.

## Floor image

`public/parquet.svg`, generated by `docs/design/generate-parquet.mjs` (`node docs/design/generate-parquet.mjs` from the repo root).

- Herringbone, 1:5 planks laid at +-45 degrees (zigzag spine vertical). Seamless tile about 600px square, about 40 planks per tile.
- Golden oak bases (`#c58a4a`, `#b97c3e`, `#d39a5a`, `#a86c34`) with little plank-to-plank contrast.
- Per plank: 11-16 wavy grain paths along the length in `#6b3f1c` (three weights), 1-2 cathedral arch groups (nested U shapes), pores, light medullary flecks, an occasional knot, all clipped to the plank. Random per plank, seeded from the plank's position modulo the tile, so tile edges match.
- Thin dark seams; soft bevel only (highlight on edges facing the top-left light, faint shadow on the opposite edges).
- Size target under 600 KB (the script prints the size). To shrink: lower `K`/`M` (fewer planks per tile) or reduce line counts.

Depth: `.plane` is oversized and tilted with `rotateX(var(--floor-tilt))` inside a `perspective` container (`perspective-origin: 50% -60%`, plane `top: -260%`), receding toward the top. Plank size on screen is `--floor-tile-size` / about 14. Decorative only (`aria-hidden`).

## Sunlight

`.sun` layer (screen blend, blurred): warm glow top right, a glossy diagonal specular band, and window-light shafts. Slow ambient drift (`--dur-sun-drift`, 28s, alternate). `.gleam`: a one-time soft light band sweeping across the floor.

## Film grain

`.grain` layer in the landing component, on top of everything (including text), `aria-hidden`, `pointer-events: none`. Inline SVG `feTurbulence` (fractalNoise, baseFrequency 0.85, stitchTiles) as a data-URI, grey, repeated.

| Token             | Value     |
| ----------------- | --------- |
| `--grain-opacity` | `0.55`    |
| `--grain-size`    | `180px`   |
| `--grain-blend`   | `overlay` |

The grain is static (no animation).

## Typography

- `--font-display`: Archivo Black (Google Fonts, `src/index.html`), fallback Arial Black, Impact. Single weight, set `font-weight: 400` to avoid faux bold.
- Wordmark is rendered uppercase via `text-transform`; DOM text and accessible name stay "parket" (h1 `aria-label`, decorative children `aria-hidden`).
- `--text-wordmark`: `clamp(2.5rem, 9vw, 8rem)`; `--tracking-wordmark`: `0.18em`.
- `--shadow-text`: soft dark double shadow for legibility.

## Motion: opening sequence (about 3.5s)

Easings: `--ease-out` `cubic-bezier(0.22, 1, 0.36, 1)`, `--ease-lux` `cubic-bezier(0.16, 1, 0.3, 1)`, `--ease-sweep` `cubic-bezier(0.45, 0, 0.2, 1)`.

| Time (s)  | Step                                                                                              | Tokens                                            |
| --------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| 0 - 2.0   | Floor fades up from dark (1.2s) while the camera eases down: scale 1.08 to 1 and tilt +6deg to rest | `--dur-floor`, `--dur-settle`                     |
| 0.9 - 2.3 | Letters rise from a baseline mask, staggered, starting slightly compressed toward the centre      | `--delay-letters`, `--dur-letter`, `--stagger-letter` |
| 1.5 -     | Sunlight turns on, then drifts slowly                                                             | `--delay-sun`, `--dur-sun-drift`                  |
| 1.8 - 3.4 | Gleam sweeps across the floor                                                                     | `--delay-gleam`, `--dur-gleam`                    |
| 2.1 - 2.9 | Hairline draws out from the centre under the word (decorative)                                    | `--delay-rule`, `--dur-rule`                      |
| 2.7 - 3.8 | One-time golden shine passes over the letters                                                     | `--delay-sheen`, `--dur-sheen`                    |

Letter mask: each letter sits in a cell clipped (`clip-path`) at its bottom edge only; the clip opens before the end so the text shadow is not cut. The shine is an `aria-hidden` copy of the word with a gradient clipped to text, animated by `background-position` (paint only, no layout). Everything else uses transform, opacity and clip-path.

`prefers-reduced-motion: reduce`: all animations off, final state shown at once (hairline visible, gleam and shine hidden, grain static).
