# Parket design system

Tokens live in `src/styles.scss` as CSS custom properties on `:root`. Never hard-code values in components.

## Mood

Warm, classy: golden-oak herringbone parquet in sunlight, white heavy uppercase sans wordmark, retro film grain.

Contrast (white wordmark): the golden oak is mid-light (about `#c58a4a`, luminance about 0.32; sun-lit up to about 0.5). Under `--veil-text` (0.62) that blends to luminance about 0.10-0.17, so roughly 5.3-7:1 against white (AA needs 4.5:1; the text is large, so 3:1). Estimated, not measured: verify on a screenshot and raise `--veil-text` alpha if a sun shaft crosses the text. The film grain at 0.55 overlay is neutral on average and does not shift luminance noticeably.

## Floor image

`public/parquet.svg`, generated by `docs/design/generate-parquet.mjs` (`node docs/design/generate-parquet.mjs` from the repo root).

- Herringbone, 1:5 planks laid at +-45 degrees (zigzag spine vertical). Seamless tile about 600px square, about 40 planks per tile.
- Golden oak bases (`#c58a4a`, `#b97c3e`, `#d39a5a`, `#a86c34`) with little plank-to-plank contrast.
- Per plank: 11-16 wavy grain paths along the length in `#6b3f1c` (three weights), 1-2 cathedral arch groups (nested U shapes), pores, light medullary flecks, an occasional knot, all clipped to the plank. Random per plank, seeded from the plank's position modulo the tile, so tile edges match.
- Thin dark seams; soft bevel only (highlight on edges facing the top-left light, faint shadow on the opposite edges).
- Size target under 600 KB (the script prints the size). To shrink: lower `K`/`M` (fewer planks per tile) or reduce line counts.

Depth: `.plane` is oversized and tilted with `rotateX(var(--floor-tilt))` inside a `perspective` container (`perspective-origin: 50% -60%`, plane `top: -260%`), receding toward the top. Plank size on screen is `--floor-tile-size` / about 14. Decorative only (`aria-hidden`).

## Sunlight

`.sun` layer (screen blend, blurred): warm glow top right, a glossy diagonal specular band, and window-light shafts. Slow ambient drift (`--dur-sun-drift`, 28s, alternate). `.gleam`: a one-time soft light band sweeping across the floor.

## Film grain

`.grain` layer in the landing component, on top of everything (including text), `aria-hidden`, `pointer-events: none`. Inline SVG `feTurbulence` (fractalNoise, baseFrequency 0.85, stitchTiles) as a data-URI, grey, repeated.

| Token             | Value     |
| ----------------- | --------- |
| `--grain-opacity` | `0.55`    |
| `--grain-size`    | `180px`   |
| `--grain-blend`   | `overlay` |

The grain is static (no animation).

## Typography

- `--font-display`: Archivo Black (Google Fonts, `src/index.html`), fallback Arial Black, Impact. Single weight, set `font-weight: 400` to avoid faux bold.
- Wordmark is rendered uppercase via `text-transform`; DOM text and accessible name stay "parket" (h1 `aria-label`, decorative children `aria-hidden`).
- `--text-wordmark`: `clamp(2.5rem, 9vw, 8rem)`; `--tracking-wordmark`: `0.18em`.
- `--shadow-text`: soft dark double shadow for legibility.

## Motion: opening sequence (about 3.5s)

Easings: `--ease-out` `cubic-bezier(0.22, 1, 0.36, 1)`, `--ease-lux` `cubic-bezier(0.16, 1, 0.3, 1)`, `--ease-sweep` `cubic-bezier(0.45, 0, 0.2, 1)`.

| Time (s)  | Step                                                                                              | Tokens                                            |
| --------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| 0 - 2.0   | Floor fades up from dark (1.2s) while the camera eases down: scale 1.08 to 1 and tilt +6deg to rest | `--dur-floor`, `--dur-settle`                     |
| 0.9 - 2.3 | Letters rise from a baseline mask, staggered, starting slightly compressed toward the centre      | `--delay-letters`, `--dur-letter`, `--stagger-letter` |
| 1.5 -     | Sunlight turns on, then drifts slowly                                                             | `--delay-sun`, `--dur-sun-drift`                  |
| 1.8 - 3.4 | Gleam sweeps across the floor                                                                     | `--delay-gleam`, `--dur-gleam`                    |
| 2.1 - 2.9 | Hairline draws out from the centre under the word (decorative)                                    | `--delay-rule`, `--dur-rule`                      |
| 2.7 - 3.8 | One-time golden shine passes over the letters                                                     | `--delay-sheen`, `--dur-sheen`                    |

Letter mask: each letter sits in a cell clipped (`clip-path`) at its bottom edge only; the clip opens before the end so the text shadow is not cut. The shine is an `aria-hidden` copy of the word with a gradient clipped to text, animated by `background-position` (paint only, no layout). Everything else uses transform, opacity and clip-path.

`prefers-reduced-motion: reduce`: all animations off, final state shown at once (hairline visible, gleam and shine hidden, grain static).

## Spacing

4px base: `--space-1` .25rem, `-2` .5, `-3` .75, `-4` 1, `-5` 1.25, `-6` 1.5, `-8` 2, `-10` 2.5, `-12` 3 (rem). Radii: `--radius-sm` 6px, `-md` 10px, `-lg` 16px, `--radius-pill` 999px.

# Designer UI (`/designer`)

Dark theme only (warm dark glass); the landing is also dark, so there is no light theme. If one is added later, override the Surfaces and Text tokens under `[data-theme='light']`. Components must use only tokens.

## Typography (UI)

- `--font-ui`: **Inter** (Google Fonts, weights 400/500/600), then system-ui stack. Frontend: add `family=Inter:wght@400;500;600` to the fonts link in `src/index.html`. Archivo Black stays display-only (wordmark, landing).
- Scale: `--text-xs` 12px (hints, units), `-sm` 14px (labels, tabs, buttons), `-md` 16px (body, inputs; 16px stops iOS zoom on focus), `-lg` 18px, `-xl` 20px (panel titles, estimate figures), `-2xl` 24px (planks to buy).
- Line height `--leading-normal` 1.5 (body), `--leading-tight` 1.25 (headings, figures). Weights `--weight-regular/medium/semibold`. Caps labels use `--tracking-caps` 0.14em. Use `font-variant-numeric: tabular-nums` for numbers.

## Surfaces and text (contrast)

## Focus ring

`--focus-ring`: 2px dark halo (`--focus-ring-halo`) plus 2px `--focus-ring-color` outside it, applied with `box-shadow` on `:focus-visible` (global rule in `styles.scss`; `outline: none` there is replaced by the ring, never removed). The dark halo makes the gold ring readable on any background, including light wall colours, the 3D view and the landing floor (halo vs ring 12.9:1). On elements that clip their shadow (overflow hidden), use `outline: 2px solid var(--focus-ring-color); outline-offset: 2px`. Canvas gets the same ring. Windows high contrast: add `@media (forced-colors: active) { :focus-visible { outline: 2px solid CanvasText; } }`.

# Plan editor (`/designer/plan`)

Dark only, same warm glass as the designer. Full visual spec per part: `docs/design/components/plan-editor.md`. Tokens are `--plan-*` in `src/styles.scss`. Everything in the SVG is drawn at constant **screen** size (`vector-effect: non-scaling-stroke`, radii and label size divided by zoom in code); only geometry follows the zoom.

## Canvas colours and contrast

Plan background `--plan-bg` `#1a110a` (luminance 0.0064, solid, no blur). Non-text ratios are computed against it (WCAG 1.4.11 needs 3:1).

| Token | Value | Ratio on `--plan-bg` | Use |
| --- | --- | --- | --- |
| `--plan-grid-minor` | `#75624d` | 3.2:1 | 10 cm lines, 1px |
| `--plan-grid-major` | `#9a8468` | 5.2:1 | 1 m lines, 1px |
| `--plan-wall` | `#e8d9c4` | 13.4:1 | wall line, 3px |
| `--plan-wall-hover` | `#f6efe6` | 15.8:1 | hover, 4px |
| `--plan-wall-selected` / handle stroke / angle text | `--accent` `#e0a85a` | 8.8:1 | selected, 5px |
| `--plan-window` | `#9cc3d6` | 9.9:1 | window symbol |
| `--plan-ghost-color` | `--text-muted` `#cdbfae` | 10.5:1 | ghost "+" |
| `--plan-error` | `#ff9b8a` | 9.1:1 | invalid state |
| `--plan-snap` | `#ffd58a` | 13.4:1 | snap indicator |
| `--plan-room-fill` | accent at 10% | decorative | room interior |

- Walls vs the minor grid (worst neighbour): 4.2:1. Accent vs the minor grid is 2.75:1, so every accent or error element that crosses the grid sits on a `--plan-casing` (`--plan-bg` stroke, `--plan-casing-extra` wider than the element): the measured pair is then the element vs the casing (8.8:1 and 9.1:1). Handles have this casing, selected walls too.
- Grid density: minor lines draw only when 10 cm is at least 8 px on screen, major only when 1 m is at least 16 px. They switch off, they never fade (fading would break 3:1). At 20 m visible width on a 360 px phone only the major grid shows.
- Text (AA 4.5:1): labels `--text-primary` with a `--plan-label-halo` stroke (4px, `paint-order: stroke`) on the plan 15.8:1, worst case over a major grid line 10:1. Angle readout `--accent` 8.8:1. Badge `--text-on-accent` on `--accent` 8.5:1. Chip and card text on `--surface-raised`: primary 14.5:1, muted 8.9:1.
- Focus ring `--focus-ring` on every SVG item: dark halo plus `#ffd58a`, 13.4:1 against the plan and 4.2:1 or more against the minor grid.

## Reduced motion, forced colours

No transitions or pans animate under `prefers-reduced-motion`. Under `forced-colors: active` map wall and handle strokes to `CanvasText`, selected to `Highlight`, grid to `GrayText`, errors to `Mark`; shapes (dash, thicker stroke, symbol) already carry the meaning.
